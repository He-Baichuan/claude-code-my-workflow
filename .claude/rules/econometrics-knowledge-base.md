# 计量经济学知识库 - DID 与结构估计

**项目重点方法**: 双重差分 (DID) 和结构估计

---

## 一、双重差分 (Difference-in-Differences, DID)

### 1. 基本原理

**识别假设**: 平行趋势 (Parallel Trends)
- 如果没有政策干预，处理组和控制组的结果变量会保持平行趋势
- 公式: E[Y₁ᵢₜ - Y₀ᵢₜ | Treatᵢ=1] = E[Y₁ᵢₜ - Y₀ᵢₜ | Treatᵢ=0]

**基本模型**:
```
Yᵢₜ = α + β·Treatᵢ×Postₜ + γ₁·Treatᵢ + γ₂·Postₜ + δ·Xᵢₜ + εᵢₜ
```

- β: DID 估计量（处理效应）
- Treatᵢ: 处理组虚拟变量
- Postₜ: 政策后时期虚拟变量
- Xᵢₜ: 控制变量

**双向固定效应 (TWFE)**:
```
Yᵢₜ = β·Treatᵢₜ + αᵢ + λₜ + εᵢₜ
```

- αᵢ: 个体固定效应
- λₜ: 时间固定效应
- Treatᵢₜ: 处理状态（0/1）

---

### 2. 平行趋势检验

#### 方法 1: 事件研究 (Event Study)
```
Yᵢₜ = Σₖ βₖ·1{t - Eᵢ = k} + αᵢ + λₜ + εᵢₜ
```

- Eᵢ: 个体 i 的政策实施时间
- k: 相对时间（k=0 为政策实施时点）
- 省略 k=-1 作为基准期

**解释**:
- 如果 β₋₅, ..., β₋₂ 在统计上不显著且接近0，支持平行趋势
- β₀, β₁, ... 显示动态处理效应

#### 方法 2: 安慰剂检验
- 使用政策前数据，假设"虚假"政策时点
- 如果虚假政策无显著效应，支持平行趋势

---

### 3. 常见问题和解决方案

#### 问题 1: 处理时间异质性 (Staggered DID)
**现象**: 不同个体在不同时间接受处理

**问题**: 经典 TWFE 可能产生负权重，导致有偏估计 (Goodman-Bacon, 2021)

**解决方案**:
1. **Callaway & Sant'Anna (2021)**: `csdid` (Stata)
2. **Sun & Abraham (2021)**: 交互加权估计量
3. **De Chaisemartin & d'Haultfoeuille (2020)**: `did_multiplegt` (Stata)

#### 问题 2: 异质性处理效应
**现象**: 不同个体处理效应不同

**解决方案**:
- 分组分析（按年龄、地区、收入水平）
- 三重差分 (DDD) 检验异质性

#### 问题 3: 预期效应 (Anticipation)
**现象**: 个体在政策实施前已调整行为

**解决方案**:
- 检查政策公布日期
- 在事件研究中检验政策前系数是否提前显著

### 5. 社会保障与养老金应用案例

**研究问题示例**:
1. 养老保险扩面对家庭储蓄的影响
2. 养老金待遇提高对老年人劳动供给的影响
3. 企业年金政策对员工留职的影响

**识别策略**:
- 利用政策推行的时间和地区差异
- 处理组: 政策覆盖地区/人群
- 控制组: 政策未覆盖地区/人群
- 处理时间: 政策实施年份

**关键变量**:
- **结果变量**: 储蓄率、劳动供给、消费
- **处理变量**: 是否参保、养老金水平
- **控制变量**: 年龄、性别、教育、收入、健康状况

## 二、结构估计 (Structural Estimation)

### 1. 基本原理

**目标**: 估计经济模型的深层参数（偏好、技术、信息结构）

**优势**:
- 能做反事实分析 (Counterfactual Analysis)
- 外推到未观察到的政策环境
- 理解行为机制

**方法**:
1. **极大似然估计 (MLE)**
2. **广义矩估计 (GMM)**
3. **模拟矩估计 (SMM/MSM)**
4. **间接推断 (Indirect Inference)**

---

### 2. 养老金结构模型典型设定

#### 生命周期模型
```
max E₀ [ Σₜ βᵗ u(cₜ) ]

s.t.
    cₜ + aₜ₊₁ = wₜ + (1+r)aₜ + Pₜ
    aₜ ≥ 0  (借贷约束)
    aᴛ = B(aᴛ₋₁, θ)  (遗产动机, 可选)
```

**参数**:
- β: 贴现因子（耐心程度）
- σ: 风险规避系数（u(c) = c^(1-σ)/(1-σ)）
- P: 养老金给付
- θ: 其他参数（遗产效用权重等）

#### 劳动供给模型
```
max u(c, l) = c^(1-σ)/(1-σ) - ψ·l^(1+η)/(1+η)

s.t.
    c = w·h + P + (1+r)a
    h ≤ h̄  (工时约束)
```

**参数**:
- ψ: 劳动不效用权重
- η: Frisch 弹性的倒数

---

### 3. 估计流程

#### 步骤 1: 求解模型（Fortran/Matlab）
```
1. 离散化状态空间（资产、收入、年龄）
2. 值函数迭代求解最优策略
3. 模拟大量个体生命周期轨迹
4. 计算模拟矩（储蓄率、劳动供给等）
```

#### 步骤 2: 选择矩条件（Stata）
从实际数据计算经验矩:
- 平均储蓄率（按年龄组）
- 劳动参与率（按年龄组）
- 资产分布的分位数
- ...

#### 步骤 3: 最小化目标函数
```
min Q(θ) = [m̂ - m(θ)]' W [m̂ - m(θ)]
 θ
```

- m̂: 经验矩（数据）
- m(θ): 模拟矩（模型）
- W: 权重矩阵

#### 步骤 4: 计算标准误
使用 Bootstrap:
1. 重抽样数据
2. 重新估计 θ
3. 重复 B 次（如 B=500）
4. 计算标准差

---

### 4. 识别

**关键问题**: 哪些数据矩能识别哪些参数？

**例子**:
- **β (贴现因子)**: 年轻时储蓄水平
- **σ (风险规避)**: 跨期消费平滑程度
- **ψ (劳动不效用)**: 劳动供给弹性

**策略**:
- 使用多个矩条件
- 参数-矩的对应关系要清晰
- 过度识别检验 (J-test)

---

### 5. 模型验证

必做检验：
- [ ] 模拟矩 vs 实际矩对比表
- [ ] 未用于估计的矩验证（外部有效性）
- [ ] 过度识别检验（p > 0.05 为好）
- [ ] 参数估计的标准误合理
- [ ] 反事实分析的合理性检验

---

### 6. 反事实分析

**例子**: 养老金待遇提高 20% 的影响

**步骤**:
1. 用估计的参数 θ̂
2. 修改养老金政策参数 P → 1.2P
3. 重新求解模型
4. 比较反事实结果与基准情景

**报告**:
- 储蓄率变化
- 劳动供给变化
- 福利变化（等价变分，EV）

---

### 7. 常见陷阱

| 陷阱 | 问题 | 预防 |
|------|------|------|
| 参数不可识别 | 多个参数给出相同矩 | 仔细选择矩条件 |
| 局部最优 | 目标函数有多个极小值 | 多起始点优化 |
| 计算错误 | 数值求解不收敛 | 检查收敛诊断 |
| 过度拟合 | 矩条件太多 | 使用主要矩，简单模型 |
