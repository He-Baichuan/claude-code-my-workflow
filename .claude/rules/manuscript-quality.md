# Word 手稿质量标准

**标准**: 发表级经济学论文

---

## 1. 结构要求

### 经济学论文标准结构
```
1. 标题页
   - 标题
   - 作者、单位
   - 摘要（中英文）
   - 关键词
   - JEL 分类号

2. 引言
   - 研究问题和动机
   - 文献综述
   - 本文贡献
   - 结构预览

3. 制度背景/理论框架
   - 相关制度介绍（如养老金政策）
   - 理论模型（如有）

4. 数据
   - 数据来源和样本
   - 变量定义
   - 描述统计

5. 实证策略/模型设定
   - 识别策略（如 DID）
   - 计量模型
   - 结构模型（如有）

6. 结果
   - 主要结果
   - 稳健性检验
   - 异质性分析

7. 结论
   - 主要发现总结
   - 政策含义
   - 研究局限

参考文献
附录（如需）
```

---

## 2. 格式规范

### 字体和排版
- **正文**: 宋体/Times New Roman, 12号, 1.5倍行距
- **标题**:
  - 一级标题（黑体/Arial, 16号, 加粗）
  - 二级标题（黑体/Arial, 14号, 加粗）
  - 三级标题（黑体/Arial, 12号, 加粗）
- **页边距**: 上下2.54cm, 左右3.17cm（或期刊要求）

### 段落
- 首行缩进 2 字符
- 段间距：段前0磅，段后6磅
- 对齐方式：两端对齐

---

## 3. 图表规范

### 图片
```
图 1: 平行趋势检验

注: 本图展示处理组和控制组在政策实施前后的趋势...
数据来源: XX数据库
```

**要求**:
- 高分辨率（300 DPI 以上）
- 坐标轴标签清晰（中英文）
- 图例位置合理
- 图注说明数据来源和关键信息
- 文件命名: `figure1_parallel_trends.png`

### 表格
```
表 1: 描述统计

变量          观测数    均值    标准差    最小值    最大值
养老保险参保   10,000   0.65    0.48     0        1
年龄          10,000   45.2    12.3     18       65

注: 样本包括...
数据来源: XX数据库
```

**要求**:
- 三线表格式（顶线、表头线、底线）
- 数值对齐（小数点对齐）
- 单位清晰
- 表注说明样本和来源
- 星号注释显著性: * p<0.1, ** p<0.05, *** p<0.01

## 4. 公式

### 使用 MathType 或 Word 公式编辑器
```
行内公式: Y_it = α + β·Treat_i×Post_t + γ·X_it + ε_it

独立公式:
                    T
    max E_0 [ Σ β^t u(c_t) ]
                   t=0

    s.t. c_t + a_{t+1} = w_t + (1+r)a_t
```

**要求**:
- 变量命名一致（斜体用于变量）
- 下标清晰
- 复杂公式独立成行并居中
- 公式编号右对齐

## 5. 引用和文献

### 正文引用格式
- **单作者**: Zhang (2020) 发现...
- **双作者**: Li 和 Wang (2019) 指出...
- **多作者**: Chen 等 (2021) 研究了...
- **括号引用**: ...已有研究发现（Zhang, 2020; Li 和 Wang, 2019）

### 参考文献格式（经济学常用）
```
期刊:
张三, 李四. 2020. "养老保险对储蓄的影响". 《经济研究》, 第5期: 45-60.

Smith, John, and Jane Doe. 2019. "The Effect of Pension on Savings."
American Economic Review, 109(5): 1234-1256.

专著:
王五. 2018. 《中国养老保险制度研究》. 北京: 经济科学出版社.

工作论文:
李六. 2021. "社会保障与养老金", 工作论文.
```

### 文献管理工具
- **推荐**: Zotero, Mendeley
- 自动插入引用
- 自动生成参考文献列表
- 格式一键切换（按期刊要求）

## 6. DID 论文特定要求

### 必须包含的内容
1. **平行趋势检验**
   - 事件研究图（图）
   - 系数表（表或正文）
   - 明确讨论平行趋势假设

2. **稳健性检验**
   - 不同控制组定义
   - 安慰剂检验
   - 不同时间窗口
   - 聚类标准误的不同方式

3. **异质性分析**
   - 分组回归（如按年龄、地区）
   - 三重差分（如适用）

4. **处理时间异质性**
   - 如果是交错 DID，讨论 Goodman-Bacon 分解
   - 考虑使用新方法（Callaway-Sant'Anna 等）

---

## 7. 结构估计论文特定要求

### 必须包含的内容
1. **模型设定**
   - 完整的数学模型
   - 参数含义清晰
   - 假设明确

2. **识别**
   - 矩条件说明
   - 参数识别的直觉
   - 排除性约束

3. **估计方法**
   - GMM/SMM/MSM 说明
   - 权重矩阵选择
   - 标准误计算（bootstrap）

4. **模型验证**
   - 模拟矩 vs 实际矩对比表
   - 过度识别检验
   - 反事实分析

5. **数值算法**
   - 求解方法说明（值函数迭代等）
   - 收敛标准
   - 计算时间（可选）

## 8. 写作质量

### 语言要求
- 逻辑清晰，论证严密
- 避免口语化表达
- 专业术语使用准确
- 中英文混排得当

### 常见错误
| 错误 | 正确 |
|------|------|
| "我们发现..." | "本文发现..." 或 "研究发现..." |
| "这个政策..." | "该政策..." |
| 第一人称过多 | 使用客观表述 |
| 缺乏量化描述 | "显著提高了X%..." |

### 论证结构
- 每段一个中心论点
- 先总后分
- 用证据支撑论点
- 段落间有过渡

- 便于导师/合作者审阅
- 保留修改历史

### 版本控制
- 文件命名: `manuscript_v1.0_20260212.docx`
- 重要版本保存副本
- Git 提交时附上版本说明

## 10. LaTeX 与 Word 互转

### Word → LaTeX
```bash
pandoc manuscript.docx -o manuscript.tex \
    --bibliography=../../Bibliography.bib
```

### LaTeX → Word
```bash
pandoc manuscript.tex -o manuscript.docx \
    --bibliography=../../Bibliography.bib \
    --citeproc
```

**注意**:
- 复杂公式可能需要手动调整
- 图表位置可能需要重新调整
- 引用格式需要检查

| 结构 | 完整、逻辑清晰 | 基本完整 | 缺失关键部分 |

| 方法完整性 | DID/结构估计关键内容齐全 | 部分遗漏 | 重大缺失 |
