# 原始工作流归档

本文件夹包含原始 Beamer/Quarto 幻灯片工作流的组件，已从主工作流移除。

## 内容

- **Quarto/** - Quarto RevealJS 幻灯片
- **docs/** - GitHub Pages 文档
- **guide/** - 工作流指南
- **rules/** - 幻灯片特定规则
  - `beamer-quarto-sync.md`
  - `no-pause-beamer.md`
  - `tikz-visual-quality.md`
- **skills/** - 幻灯片特定技能
  - `deploy/`, `qa-quarto/`, `slide-excellence/`, 等
- **agents/** - 幻灯片特定代理
  - `beamer-translator.md`, `quarto-critic.md`, 等

## 用途

这些文件已归档以保持主工作流专注于经济学论文研究（Stata + Fortran + Word）。

如果将来需要创建学术幻灯片工作流，可以参考这些文件。

## 来源

原始工作流来自: [pedrohcgs/claude-code-my-workflow](https://github.com/pedrohcgs/claude-code-my-workflow)
