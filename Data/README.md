# 数据文件夹

## 结构

- **Raw/** - 原始数据（只读，不修改）
- **Cleaned/** - 清洗后的分析数据
- **Results/** - 分析结果（回归输出、描述统计等）

## 数据溯源要求

每个数据文件应在此记录：

### 示例条目

**数据集名称**: 养老保险参保数据 2010-2020
- **来源**: 国家统计局 / XX 调查
- **获取日期**: 2024-XX-XX
- **原始文件**: `Raw/pension_data_2010_2020.dta`
- **清洗脚本**: `Code/Stata/01_clean_pension_data.do`
- **输出文件**: `Cleaned/pension_analysis_ready.dta`
- **变量数**: XX 个
- **观测数**: XX 个
- **关键变量**:
  - `pension_enroll`: 是否参保 (0/1)
  - `age`: 年龄
  - `income`: 收入
